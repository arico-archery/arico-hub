## 1. 請求書取引の一括投入（2026年1〜7月分）

自社EC以外の取引（学校・協会・店頭など）は紙の請求書で処理していた。
2026年1〜7月の283件を CSV（請求書一覧）と PDF（品目明細）から復元して投入した。

- 受注番号 `ORD-<受注日>-I<連番>`、`externalOrderNo = INV-<取引ID>`
- 状態は `delivered` + `received`（既に終わった取引なので発注・バックオーダーに出さない）
- **合計 ¥35,034,476 / 未収 54件 ¥5,536,976** — 元の CSV と一致することを確認済み
- 品目 1,725行のうち **97.1% が実在の仕入先商品に直結**（残りは ETC）

### 除外したもの（意図的）
社内取引（ARICO ARCHERY 65件）／仕入先への支払（WJ・KOREA 4件）／
オンライン集計行（6件・MakeShop 取込分と二重計上になる）／無償0円（118件・スポンサー・不良交換・サンプル）

### 未投入 5件（PDF が見つかっていない、¥845,685）
成城大学 吉田優希(18929)・加藤はな(19024)・安井(19039, 19858, 19882)。
PDF が出てきたら抽出 → 投入スクリプトを再実行すれば埋まる。

### 金額が合わないときの考え方
CSV と PDF の金額差は解析ミスではなく `小計値引` `調整分` や複数ページが原因だった。
**請求額を正とし、差額は値引きとして吸収する**方針で処理してある。

## 2. カタログのマッチング整備

原価はカタログのリンク経由で決まるので、リンクの誤りが利益計算を直撃する。

- 2026-07-31: マッチング740件を全数監査 → 疑わしい55件を抽出（誤マッチ／左右逆／ダース↔バラ／価格データ／規格）
- 2026-08-01〜08-11: 担当者が画面から手作業で整理（約90%完了）
- 2026-08-11: **遡及適用** — 全受注品目3,975件のうち **888件を貼り替え**、
  受注の原価合計を再計算。原価合計の変動は +¥31,853 とごく僅か。
  解釈できなかった822件は**触らず保存**、原価が不自然になる45件は商品だけ繋ぎ替えて原価は据え置き。

### TENPRO の仕入先は FIVICS（確定）
SHIBUYA は FIVICS ブランドも扱っているため日本語名が完全一致してしまい、
SHIBUYA に誤マッチしていた。**ブランド ≠ 仕入先**であることに注意。
なお スピンウィング（RANGE-O-MATIC）は SHIBUYA が最安なので SHIBUYA のままが正しい。

## 5. 単位（バラ↔ダース／1個↔パック）の不一致 — 未解決

仕入先の価格が「12本入り」「10個入り」なのに、こちらは1個単位で売っているケース。
原価が実際の6〜58倍になり逆ざやに見える。

現在**逆ざや20件**あり、内訳は:
- **単位の不一致 11件**（JVD がパック・ダース単価）… SHIBUYA に1個単位の同等品があるものが多く、
  マッチング先を変えるのが最も簡単
- **【バラ】表記なのにダースにリンク 3件**（FIVE-X / TENPRO / GOLDRO シャフト）… 原価 ÷12 で対応した前例あり
- **単位と無関係 6件** … 売価・原価そのものの確認が必要

対応方針は保留中（→ `05-open-issues.md`）。

## 6. 商品データの既知の壊れ

- **`Specialty ピープインサート` のサイズが `1月8日` `1月16日`** — Excel が `1/8` `1/16` を日付として
  解釈した痕跡。サイズ欄での検索・照合が効かない。分数サイズの商品は他にもある可能性あり。
- **SHIBUYA のデータセットが2種類ある** — Web クロール由来（`productCode` が `0000…`、希望小売価格ベース、
  1,346件）と、旧商品データファイル由来（`SBY-…`、販売価格ベース、14,313件）。
  受注に使うのは前者。後者をどうするかは未決。
- **ANGEL DX-WP クィーバー** — 色の欄にサイズ(S/M/L)が入っている。オーダーメイド商品で
  「本体カラー」等の仕様は備考にある。カタログの再リンクが未了。
